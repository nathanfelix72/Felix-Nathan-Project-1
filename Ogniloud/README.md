#  Ogniloud

This project is a simplified version of a language learning app. It is named Ogniloud after Duolingo, and is named such since it is Duolingo spelled backwards.

The project consists of multiple topics, which functionality to read a lesson about the topic, reivew the vocabulary list and review flashcards, and then to take a quiz on the topic. You can track your progress and try to get 100% on all the quizzes!

There are a lot of features, including some not in required description. Here are some of them I also mention in the rubric excel sheet:

"I added nice pictures for each of the topics so the topic select looks super nice! I also keep track of the flashcards as you flip them. If you go into the flashcard activity and review half of them, your progress in the progress section will show that you've completed half of them. You can mark/unmark individual flashcards or all at once if you want, but this will make it so you don't have to manually mark as complete the flashcards."

Overall it was a fun project. I put in an average of 2 hoursa day for that past two weeks and learned a lot, although I definitely had a lot of difficulties. I met all the requirements though and hope that you enjoy using the app!
